# Third-party components

- Google IFEval verifier: vendored under `third_party/google_ifeval` for the
  fixed evaluation protocol used by this project. Upstream project:
  <https://github.com/google-research/google-research/tree/master/instruction_following_eval>.
- AllenAI Open Instruct IFEval functions: vendored under
  `third_party/open_instruct_ifeval`. Upstream project:
  <https://github.com/allenai/open-instruct>.
- KaTeX browser assets: vendored under `ui/vendor/katex`; its upstream license
  is retained in that directory.
- InternViT and MiniCPM weights are not redistributed in this GitHub repository.

Dataset licenses remain governed by their upstream repositories. Training data
is deliberately excluded from source control.
