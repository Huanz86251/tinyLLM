# Text data builders

这里保留了实际使用过的文本数据构建脚本，并按用途重新命名：

- `base_*`：初始预训练的中文、英文故事、代码、数学和 Cosmopedia 混合；
- `cpt_*`：继续预训练的推理池与语言锚定池；
- `long_*`：8K / 16K 长上下文原料；
- `sft_*`：通用 SFT 的数学、中文多轮、英文多轮、代码、工具和长上下文数据。

这些脚本原来分散在本地和旧云端目录中，数据集选择、字段转换、长度过滤和去重逻辑保持不变。运行前需要把脚本顶部的 tokenizer、输出目录和缓存目录改成当前机器路径。训练数据本身不提交到 GitHub。
